title: Split
summary: Two regions side by side at a set ratio, stacked on narrow screens.
milestone: M3b
level: layout
our-choice: No standard exists for a fixed split: two regions in a CSS grid. A draggable divider would follow the APG Window Splitter pattern.
specs:
  - APG Window Splitter pattern: https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/
  - WCAG 1.4.10 Reflow: https://www.w3.org/WAI/WCAG22/Understanding/reflow.html
