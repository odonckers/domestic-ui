milestone: M3
level: organism
standard:
  - HTML `<dialog>` element: https://html.spec.whatwg.org/multipage/interactive-elements.html#the-dialog-element
  - APG Dialog (Modal) pattern: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/
specs:
  - MDN `<dialog>`: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog
sources:
  - dialog
  - drawer
keyboard:
  - Tab / Shift+Tab: moves focus through the focusable elements inside the dialog; a modal dialog keeps focus inside.
  - Escape: closes the dialog; focus returns to the element that opened it.
