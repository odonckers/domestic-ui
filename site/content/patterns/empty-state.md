milestone: M3b
level: molecule
our-choice: A composition, not a component: a `data-card` section with a heading, one muted sentence and a cluster of button links.
sources:

specs:

- Put the empty state where the list or table would be, under the same page heading, so the page keeps its structure.
- Say what will appear here and how to add it. The first action is the primary button; any other is secondary.
- After a search or filter that matches nothing, say so and offer to clear it, rather than suggesting the person create something.
