title: App shell
summary: The frame of an application: header, primary sidebar, main content and an optional auxiliary sidebar.
milestone: M3b
level: layout
our-choice: No standard defines an app shell: the landmarks `<header>`, `<nav>`, `<main>` and `<aside>`, placed with CSS grid.

  - HTML `<aside>` element: https://html.spec.whatwg.org/multipage/sections.html#the-aside-element
  - WCAG 1.4.10 Reflow: https://www.w3.org/WAI/WCAG22/Understanding/reflow.html
