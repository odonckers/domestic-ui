Base elements

Every element on this page is plain HTML styled by the base layer. There are no component classes. Read the WHATWG HTML Living Standard for what each element means; this page only shows how it looks.

A paragraph with a link to this section, some strong importance, stress emphasis, a highlighted run, an abbreviation like WCAG, inline <code>, sample output Saved., and keyboard input Ctrl + K. Prose is capped at a comfortable measure so lines stay readable on wide screens.

What is a cascade layer?

A named bucket of styles. Layers declared earlier lose to layers declared later, regardless of selector specificity. See @layer on MDN.

Why keep link underlines?

Color alone must not be the only way to identify a link (WCAG 1.4.1).
