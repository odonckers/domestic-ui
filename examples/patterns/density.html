Density

The same toolbar, form and table at comfortable and compact density, side by side.

API: data-density="compact" on any element tightens everything inside it; data-density="comfortable" is the default and restores it inside a compact area. Density changes control heights, padding and gaps, never the size of text. Compact controls stay at least 32px tall, above the 24 by 24 CSS pixels of WCAG 2.5.8 Target Size (Minimum). Source: the density tokens in css/tokens/semantic.css; see the density explainer.

Comfortable inside compact

Density is inherited, so a nested data-density="comfortable" brings back the default sizes for one part of a compact screen.
