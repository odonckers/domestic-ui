List-detail

A list of orders beside the selected order: side by side when the wrapper is wide, stacked when it is narrow.

API: data-list-detail on a wrapper of two children, the list (a <nav aria-label> holding a list of links) and the detail (a <section> named by its heading); aria-current="page" on the selected link. Source: css/layout/list-detail.css.

Each item is a real link to the order's own URL, so history, bookmarks and "open in new tab" work, and the page works with JavaScript off. In this demo every link opens this page; an application renders the chosen order. The layout follows the width of its wrapper (a container query), not the viewport, so it also works inside a split or an app shell.
