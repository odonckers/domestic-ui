App shell: content on the frame

By default main is a panel that scrolls inside itself beside the sidebars. data-app-shell="page" opts out: main sits on the frame, each data-card directly in it is a panel, and the page scrolls under a sticky app bar. Scroll inside this box to see it. The default is on the app shell example.
