App shell

The frame of an application: an app bar, a primary sidebar, the main content and an optional auxiliary sidebar, each a native landmark placed with named grid areas.

API: data-app-shell on <dui-app-shell> (or any wrapper) holding a <header>, the primary sidebar (a labelled <nav>), <main> and an optional <aside>; toggle buttons with aria-controls and aria-expanded, hidden until the script shows them. data-app-shell="contained" keeps the shell inside a box --dui-size-pane tall. Source: css/layout/app-shell.css and web-components/dui-app-shell.js.

The shell follows its own width, not the viewport. This one is about 69rem wide on a desktop screen, so both sidebars sit beside main, and main is narrow enough that the list-detail inside it stacks. Make the window narrower: under 64rem the details sidebar becomes a drawer at the end, under 48rem the navigation becomes a drawer at the start. With JavaScript off every part is always visible. The full screen is in the orders example.
