Layouts

Page layouts for application screens, each one attribute on a wrapper, built with CSS grid and container queries.

These layouts follow the width of their own wrapper, not the viewport, so they work inside each other and inside the main area of an application. The small primitives (.stack, .cluster, .grid and data-scroll) are on the base elements page.
