Navigation list

A <nav> of links with aria-current="page" and collapsible groups. No JavaScript.

API: data-nav="vertical | horizontal" on <nav aria-label>, aria-current="page" on the current link, <details> for groups. Source: css/components/molecules/nav.css.

This is the APG disclosure navigation example with native <details> instead of scripted buttons. It is not an ARIA menu: site links belong in a list that Tab moves through. The current page has an accent bar, a tint and bold text.

Vertical (sidebar)

  • Overview
  • Projects
    • Active
    • Archived
  • Settings
    • Profile
    • Billing
<nav aria-label="Sidebar example" data-nav="vertical">
  <ul>
    <li><a href="#vertical-title">Overview</a></li>
    <li>
      <details open>
        <summary>Projects</summary>
        <ul>
          <li><a href="#vertical-title" aria-current="page">Active</a></li>
          <li><a href="#vertical-title">Archived</a></li>
        </ul>
      </details>
    </li>
    <li>
      <details>
        <summary>Settings</summary>
        <ul>
          <li><a href="#vertical-title">Profile</a></li>
          <li><a href="#vertical-title">Billing</a></li>
        </ul>
      </details>
    </li>
  </ul>
</nav>

Horizontal (top bar)

Groups open as dropdowns. They share a name, so opening one closes the other.

  • Home
  • Products
    • Design system
    • Icons
  • Company
    • About
    • Careers
  • Contact
<nav aria-label="Top bar example" data-nav="horizontal">
  <ul>
    <li><a href="#horizontal-title" aria-current="page">Home</a></li>
    <li>
      <details name="top-bar">
        <summary>Products</summary>
        <ul>
          <li><a href="#horizontal-title">Design system</a></li>
          <li><a href="#horizontal-title">Icons</a></li>
        </ul>
      </details>
    </li>
    <li>
      <details name="top-bar">
        <summary>Company</summary>
        <ul>
          <li><a href="#horizontal-title">About</a></li>
          <li><a href="#horizontal-title">Careers</a></li>
        </ul>
      </details>
    </li>
    <li><a href="#horizontal-title">Contact</a></li>
  </ul>
</nav>
