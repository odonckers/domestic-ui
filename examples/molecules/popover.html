Popover and tooltip

The popover attribute, anchored with CSS, and a tooltip that follows WCAG 1.4.13.

API: data-popover="[block-start | inline-start | inline-end]" on a [popover]; role="tooltip" on a popover="hint" inside <dui-tooltip>. Source: css/components/molecules/popover.css.

A button with popovertarget opens the popover with no script; Esc or a click outside closes an auto popover. CSS anchor positioning places it next to its button and flips it near the edges; without anchor positioning it sits centered at the bottom of the viewport.

Popover

Anyone with the link can view this page.

<button type="button" popovertarget="share-popover">Share</button>
<div id="share-popover" popover data-popover>
  <p>Anyone with the link can view this page.</p>
</div>

Above the button, with a close button

popover="manual" does not light-dismiss: close it with a button (popovertargetaction="hide").

Need a hand?

Read the guide or ask in the forum.

<button type="button" popovertarget="help-popover">Help</button>
<div id="help-popover" popover="manual" data-popover="block-start">
  <p><strong>Need a hand?</strong></p>
  <p>Read the <a href="../../README.md">guide</a> or ask in the forum.</p>
  <button type="button" popovertarget="help-popover" popovertargetaction="hide" data-button="small">Close</button>
</div>

Tooltip

The tooltip describes the button (aria-describedby); the button keeps its own name. It shows on hover and on keyboard focus, hides on Esc, and you can move the pointer onto it. HTML cannot open a popover on hover yet (interestfor is coming), so <dui-tooltip> does it.

Shortcut: Ctrl+S Copies the page address 
<div class="cluster">
  <dui-tooltip>
    <button type="button" aria-describedby="save-tip">Save</button>
    <span id="save-tip" popover="hint" role="tooltip">Shortcut: Ctrl+S</span>
  </dui-tooltip>
  <dui-tooltip>
    <button type="button" aria-label="Copy link" aria-describedby="copy-tip" data-button="quiet">⧉</button>
    <span id="copy-tip" popover="hint" role="tooltip">Copies the page address</span>
  </dui-tooltip>
</div>
