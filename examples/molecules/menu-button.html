Menu button

A button that opens a list of actions: a popover plus the APG Menu Button keyboard behavior.

API: <dui-menu> around a <button popovertarget> and a [popover][data-popover] of buttons. Source: css/components/molecules/menu-button.css.

The button opens the popover natively. <dui-menu> (web-components/dui-menu.js) adds aria-haspopup="menu", aria-expanded, role="menu" and role="menuitem", and the APG Menu Button keys. With JavaScript off the actions are plain buttons.

Actions menu

Links are not a menu

When the items go to other pages, use a disclosure: a popover (or <details>) holding a list of links, with no menu roles. Tab moves through the links, as screen reader users expect on the web.
