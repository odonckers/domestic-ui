Combobox (typeahead)

A text field that suggests values as you type: a native <input list> and <datalist>, upgraded to the APG Combobox list autocomplete pattern.

API: <dui-combobox> around a <label>, an <input list> and its <datalist>. Source: css/components/molecules/combobox.css.

With JavaScript off the browser suggests the datalist values itself. <dui-combobox> (web-components/dui-combobox.js) keeps the same input, removes its list attribute, builds a listbox from the options and adds the APG Combobox keys. Options match when they contain what you type. See the combobox explainer.

Suggestions from a datalist

In a form

The input is the form control, so its name and value are submitted as usual. Accepting an option fires change on the input.

Options loaded by the page

Cancel the dui-combobox-filter event to filter elsewhere, such as on a server, then hand the results to setOptions(). This demo searches a local list after a short delay; there is no network request.
