Pagination

Links between the pages of a long list: a named <nav>, a list, and aria-current="page".

API: data-pagination on <nav aria-label="Pagination">, aria-current="page" on the current page, <a> without href for a disabled end. Source: css/components/molecules/pagination.css.

There is no native element or APG pattern for pagination, so this is a written contract: the pagination explainer. Number links read "Page 5" thanks to visually hidden text, and the current page is a filled box with bold text.
