Breadcrumb

The trail of pages leading to this one: a named <nav>, an ordered list and aria-current="page".

API: data-breadcrumb on <nav aria-label="Breadcrumb">, aria-current="page" on the last link. Source: css/components/molecules/breadcrumb.css.

This is the APG Breadcrumb pattern. The slashes are CSS generated content with empty alternative text, so screen readers do not read them. The current page uses the text color and bold weight, and keeps its underline.
