Atoms

Atoms add the minimum on top of the base layer. Each has one attribute API.

Plain HTML already looks right with the base layer; atoms cover what native elements cannot say on their own, such as button emphasis or a status label. The full reference, with the reasoning behind each choice, is in css/components/atoms/README.md.
