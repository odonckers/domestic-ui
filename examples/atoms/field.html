Field

One control with its label, hint and error message.

API: data-field on the wrapper, data-field="hint" and data-field="error" on the messages. Source: css/components/atoms/field.css.

The label names the control. The hint and error are in the control's aria-describedby, so they are read as its description. An invalid control has aria-invalid="true". The error starts with the word "Error:" and the control gets a thick start border, so the state never relies on color alone.
