Icon

Inline SVG icons from Lucide, pasted into the page and colored by the text around them.

API: data-icon (or data-icon="mirror") on an inline <svg>; data-button="icon" on an icon-only button. Source: css/components/atoms/icon.css and css/components/atoms/button.css.

Copy an icon from lucide.dev, replace its class with data-icon and add aria-hidden="true" focusable="false". Nothing is installed: the SVG is the icon. Stroke and fill stay currentColor, so the icon follows the theme and forced colors. Icon plus a visible label is the default; label only is always fine; icon only is for a short list of well-known actions (see PRINCIPLES.md, Icons).

Icon and label

The default. The icon is decoration: the visible word is the button's name.

Icon only, with a tooltip

Only for a well-known action. The name is visually hidden text in the button and names the action, not the picture. The tooltip shows the same words on hover and on keyboard focus, Esc hides it, and the pointer can move onto it (WCAG 1.4.13). It repeats the name, so it is aria-hidden: screen readers hear the name once. The button is a square of the control size, never smaller than 24 by 24 pixels.

Don't: an icon-only delete

Never make a destructive action icon only. A trash can alone is easy to misread and easy to hit; write the word. Delete, remove, empty and reset get a visible label, with the icon beside it if you like, and a confirmation <dialog> when the data cannot come back.
