Quiet link

A link that takes the color of the text around it, for dense UI where many accent-colored links are noisy.

API: data-link="quiet". Source: css/components/atoms/link.css.

It keeps its underline, so color is never the only way to spot it (WCAG 1.4.1 Use of Color). Use regular links in prose; use quiet links where links repeat, such as table cells and metadata.
