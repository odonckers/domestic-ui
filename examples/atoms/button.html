Buttons

Native <button> with one attribute for variant and size.

API: data-button="[primary | secondary | quiet] [small | large]". Source: css/components/atoms/button.css.

Without the attribute, the base layer already styles buttons: type="submit" is the primary action and every other button is neutral. data-button overrides that when the native type does not match the emphasis you want. Use <button> for actions and <a href> for navigation (APG button pattern).

Variants

Primary for the main action, secondary for the rest, quiet for low-emphasis actions next to others.

<div class="cluster">
  <button type="button" data-button="primary">Primary</button>
  <button type="button" data-button="secondary">Secondary</button>
  <button type="button" data-button="quiet">Quiet</button>
</div>

Native default

A submit button is primary with no attribute. Opt out with secondary.

<form action="#native-title" class="cluster">
  <button type="submit">Publish</button>
  <button type="submit" name="draft" value="1" data-button="secondary">Save draft</button>
  <button type="reset" data-button="quiet">Clear</button>
</form>

Sizes

Default and large are at least 44px tall. Small is 32px: below 44px but above the 24px minimum of WCAG 2.5.8 Target Size (Minimum). 

<div class="cluster">
  <button type="button" data-button="primary small">Small</button>
  <button type="button" data-button="primary">Default</button>
  <button type="button" data-button="primary large">Large</button>
</div>

Links that look like buttons

Same attribute on <a href>. It is still a link: it navigates, opens in a new tab and is announced as a link.

Create account Read the guide Skip for now 
<div class="cluster">
  <a href="#links-title" data-button="primary">Create account</a>
  <a href="#links-title" data-button="secondary">Read the guide</a>
  <a href="#links-title" data-button="quiet">Skip for now</a>
</div>

Disabled

The disabled attribute removes the button from the tab order and blocks activation. Use it when the action is simply not available. 

<div class="cluster">
  <button type="button" data-button="primary" disabled>Delete</button>
  <button type="button" disabled>Archive</button>
</div>

Disabled but focusable

aria-disabled="true" looks disabled and is announced as disabled, but stays in the tab order, so keyboard and screen reader users can find it and read why. APG recommends this for controls whose reason matters (focusability of disabled controls). It does not block clicks: your script must ignore them (see the script at the end of this page).

Add a title before publishing.

<div class="cluster">
  <button type="button" data-button="primary" aria-disabled="true" aria-describedby="publish-why">Publish</button>
  <p id="publish-why" data-text="small muted">Add a title before publishing.</p>
</div>

Loading

An honest loading state: the visible label says what is happening, aria-busy="true" and aria-disabled="true" are set while it runs, focus stays on the button, and the result goes to a role="status" region. There is no spinner that replaces the label. 

<div class="cluster">
  <button type="button" id="save-demo" data-button="primary">Save changes</button>
  <p id="save-status" role="status" data-text="small muted"></p>
</div>
