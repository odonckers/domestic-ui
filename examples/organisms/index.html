Organisms

Larger sections of a screen built from molecules, atoms and native elements, each with one attribute API.

Each organism adapts to the width of its own box with a container query, so it fits a full page, a split region or the main area of an application alike. The full reference is in css/components/organisms/README.md; the page layouts they sit in are on the layouts page.
