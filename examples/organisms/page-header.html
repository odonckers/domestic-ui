Page header

The top of a screen: breadcrumb, title, a short description and the page's actions.

API: data-page-header on a <header> inside <main>, holding an optional breadcrumb <nav>, the heading, an optional <p> and, last, an element with the actions. Source: css/components/organisms/page-header.css.

The actions sit beside the title when the header is at least 40rem wide and wrap under it when it is narrower (a container query on the header). On a real page the title is the page's <h1>; these demos use <h3> so the headings of this page stay in order.
