Filter bar

Native form controls that narrow a list, with the number of results as a status message.

API: data-filter-bar on a <search> holding a <form> of labelled fields whose last child holds Apply and Reset, then a role="status" element with the result count. Source: css/components/organisms/filter-bar.css.

The form uses method="get", so the filters end up in the URL and work with JavaScript off. The small script on this page filters the table in place instead and updates the status text, which screen readers announce without moving focus (WCAG 4.1.3 Status Messages).
